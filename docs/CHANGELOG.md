## 2026-11-02：修复窑火吉祥物烤火时营火闪烁

- 原因：烤火时 `data-stoked` 把三帧火焰的动画时长从 0.54s 改为 0.4s，但错开延迟仍写死为 -0.18s/-0.36s（对应 0.54s），三帧相位错乱，同一时刻出现全空或多帧叠加。用 Web Animations 逐点采样，烤火状态 60 个采样点中 27 个不是“恰好一帧可见”（14 个全空、13 个叠加），平时为 0。
- 修复：火焰周期改为变量 `--flame-t`（默认 0.54s，烤火 0.4s），两帧延迟用 `calc(var(--flame-t) / -3)` 与 `calc(var(--flame-t) * -2 / 3)` 推导，不再单独改帧时长。切换速度时三帧保持同相，不会再有空帧或叠帧。仅窑火主题样式，无脚本、接口或数据变化。
- 验证：临时 Node 24.22.1 下 38 项测试（新增样式回归，旧样式上失败、新样式通过）37 通过、1 项仅限 Linux 的锁测试跳过，类型检查通过。浏览器采样：平时、烤火、退出烤火三种状态各 120 点均为 0 次异常；烤火开关每 330ms 反复切换 4 秒共 452 次实时采样，每次恰好一帧可见；烤火时静态截图火焰正常。预览窗格会降低帧率，真实设备流畅度未实测。
