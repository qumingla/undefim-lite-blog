## 源码基线

- 使用 Docker Compose 运行单个写入实例，反向代理提供 HTTPS。
- 保存草稿与静态发布分离，数据库与备份不进入公开产物。
- CDN 缓存响应头及可选刷新接口已实现；实际是否启用边缘缓存由部署配置决定。
- 数据库、开发数据、凭据、备份、迁移报告与截图受忽略规则保护。发布前还需人工检查文档和源码中的个人信息及实际运维细节，不能只依赖文件路径或密钥模式扫描。
