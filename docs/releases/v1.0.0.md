# v1.0.0

## Highlights

- 将原有 Halo 博客重构为零依赖 Node.js 轻量博客
- 保留文章、分类、关于、友链、搜索、访客统计等核心能力
- 增加隐藏后台，可管理文章、页面、友链和站点设置
- 支持 Docker Compose 部署
- 导入器可从源站抓取内容并镜像静态资源

## Included

- 三栏首页和文章详情布局
- 本地 JSON 存储
- 暗色主题切换
- 点击烟花和背景氛围特效
- GitHub Actions CI
- Dockerfile 和 Compose 配置

## Deploy

### Local

```bash
npm run import
BLOG_ADMIN_PASSWORD='your-strong-password' \
BLOG_ADMIN_PATH='/dashboard-unsafe-to-guess' \
npm start
```

### Docker Compose

```bash
cp .env.example .env
docker compose up -d --build
```

## Notes

- 首次上线前必须修改后台密码和后台路径
- `storage/site.json` 需要纳入版本控制
- `storage/stats.json` 属于运行期数据，不建议提交
